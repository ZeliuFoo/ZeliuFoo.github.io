# zeliufoo.github.io

Personal academic homepage, live at https://zeliufoo.github.io

Built with [Academic Pages](https://github.com/academicpages/academicpages.github.io) (Jekyll) and deployed by GitHub Actions on every push to `master`.

- Front page: `_pages/about.md`
- Sidebar (name, photo, links): `author:` block in `_config.yml`
- Photo: `images/profile.jpg`
- PDFs (CV, papers): put in `files/`, link as `/files/xxx.pdf`
